I designed and coded this site myself using the Docs as Code paradigm and the following tools:
- [Docusaurus](https://docusaurus.io/) static site generator
- Visual Studio Code
- Git
- GitHub

The Docusaurus code and Markdown content files are saved on my [public GitHub account repository](https://github.com/kkerr99/kris.kerr.professional.website).

I used [GitHub Pages](https://github.com/kkerr99/kris.kerr.professional.website/actions) to build, deploy, and host this site.
